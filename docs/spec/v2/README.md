# &ND Core v2

This folder is the `&ND Core v2` proposal track.

## Stage

`&ND Core v2` is currently in **proposal** stage.

The proposal stage is intentionally exploratory. Design choices may be revised, replaced, split,
or removed as constraints become clearer.

Current compatibility direction: treat v1 as a subset of v2 while v2 proposal work stabilizes.

## Scope For Now

- define the extension goals that require a v2 line
- promote selected syntax reserved in v1 into explicit v2 constructs
- keep proposal seeds, executable fixtures, and parser behavior aligned
- enforce the explicit v1/v2 compatibility matrix
- define canonical output and migration expectations before promotion to draft
